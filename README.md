# Java Fundamentals ☕

A collection of exercises and small programs written while studying the fundamentals of Java. This repository is part of my learning journey toward becoming a junior software developer.

---

### 🎯 Purpose

This repo is used to practice and consolidate core Java concepts through hands-on exercises, including:

- Variables, data types, and operators
- Conditional statements (`if`, `else`, `switch`)
- Loops (`for`, `while`, `do-while`)
- Arrays and collections
- Methods and functions
- Object-Oriented Programming (classes, objects, inheritance, polymorphism, encapsulation, abstraction)
- Exception handling
- Basic input/output (I/O)
